# ASCII Assets

Terminal/textmode brand experiments for Palimpsest / 忘筌.

Preferred toolchain:

- `durdraw` for hand-authored ASCII/ANSI art in the terminal.
- `bit` for terminal logo typography and ANSI banner experiments.
- `textmode.js` for future animated web/canvas textmode scenes.
- `artem` or `RASCII` for converting bitmap sketches into rough ASCII drafts.

Current assets:

- `palimpsest-goldfish.txt`: minimal plain-text goldfish mark for README, terminal splash, or CLI banner.
